================================================================================
KEY FEATURES IMPLEMENTED
================================================================================

1. Lambda Layer for Shared Code
   - Contains scraper module (all scraper classes)
   - Contains analytics module (calculators, models, scoring)
   - Includes numpy, httpx, beautifulsoup4 dependencies

2. Event-Driven Architecture
   - EventBridge Schedule triggers scraper daily at 2 AM UTC
   - Scraper publishes ScraperComplete event
   - ScraperComplete event triggers analyzer
   - Analyzer publishes AnalysisComplete event

3. Graceful Fallback
   - Both handlers work without the layer deployed
   - Falls back to existing service implementations
   - No breaking changes to existing functionality

4. Property Data Flow
   - Scraper collects properties from 4 sources:
     * SimonEstates
     * FrankSalt
     * Remax
     * Dhalia
   - Properties saved to DynamoDB PropertiesTable
   - Raw data archived to S3

5. Analysis Data Flow
   - Analyzer processes properties without ROI scores
   - Re-analyzes top properties (ROI score > 50)
   - Uses analytics module for accurate calculations
   - Results saved to DynamoDB AnalysisTable

================================================================================
DEPLOYMENT
================================================================================

Prerequisites:
- AWS CLI configured
- SAM CLI installed
- Docker (for building layer)

Build Steps:
1. ./scripts/build_layer.sh
2. sam build
3. sam deploy --config-env dev

Environment Variables:
- PROPERTIES_TABLE
- ANALYSIS_TABLE
- SCRAPER_RUNS_TABLE
- EVENT_BUS_NAME
- RAW_DATA_BUCKET
- PYTHONPATH=/opt/python:/var/task
